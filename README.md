# นโยบายความเป็นส่วนตัว — โต๊ะแป้ง (Tohpang)

repo นี้มีไฟล์เดียว: หน้านโยบายความเป็นส่วนตัวของแอป **โต๊ะแป้ง**

📄 อ่านฉบับเผยแพร่: https://eskub.github.io/tohpang-privacy/

---

## ทำไมถึงเป็น repo แยก

ซอร์สโค้ดของแอปอยู่ใน repo **ส่วนตัว** อีกที่หนึ่ง · GitHub Pages เปิดจาก repo ส่วนตัว
ไม่ได้ถ้าไม่ได้ใช้แพ็ก Pro และการเปิด Pages จากโฟลเดอร์ `docs/` ของ repo นั้นจะทำให้
เอกสารภายในทั้งหมด (บันทึกการตัดสินใจ รายการงาน แผนที่ข้อมูล) กลายเป็นสาธารณะไปด้วย

repo นี้จึงมีเฉพาะสิ่งที่ **ตั้งใจให้เป็นสาธารณะ** เท่านั้น

## แก้ยังไง

แก้ `index.html` แล้ว commit — GitHub Pages อัปเดตให้เองภายในไม่กี่นาที

ต้นฉบับที่ใช้เขียนอยู่ที่ `docs/privacy/index.md` ใน repo ของแอป · **แก้ที่นั่นด้วยทุกครั้ง**
ไม่งั้นสองที่จะไม่ตรงกัน และฉบับที่ผู้ใช้เห็นจะไม่ใช่ฉบับที่ทีมคิดว่าเผยแพร่อยู่

ทุกครั้งที่แก้เนื้อหาที่มีผลกับสิทธิของผู้ใช้ ให้เปลี่ยนเลขฉบับ (`th-1.0`) ด้วย
